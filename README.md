# 🧠 Brain Games – Python Mini Project

A beginner-level Python project featuring **four interactive brain games** in one program:

🔤 **Word Scramble Game** – Unscramble the given letters and guess the original word.
🧮 **Maths Quiz** – Solve mathematical questions by choosing the correct option.
🧩 **Riddle Game** – Solve riddles using your logic and get hints when needed.
🔐 **Code Breaker Game** – Use the given clues to find the correct four-digit number.

### ✨ Features

* Interactive user input
* Hints for difficult questions
* Try-again functionality
* Voice interaction using `pyttsx3`
* Colored and styled console interface
* ASCII-art game titles using `pyfiglet`

### 🐍 Python Concepts Used

* Variables and data types
* `if-elif-else`
* `for` and `while` loops
* Functions
* Lists and dictionaries
* String handling
* User input
* Python modules and libraries

This project was created as a **beginner-level Python practice project** to understand programming logic.
